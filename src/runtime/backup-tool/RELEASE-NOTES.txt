开放空间采集工具 · 1.0.12-launcher-integration
适用平台：Windows 10/11 x64

这是启动器对用户提供的 Windows 1.0.12 新手增强工具的择优集成，不是原包整体覆盖。

已融合
- 三步采集指南、只读依赖预检查与清晰的结果目录/账号ZIP导航。
- 探索观测报告：来自成功解码的服务端响应，生成 exploration.json / exploration.txt 并放进账号ZIP。
- 区分未采到、明确0、部分场景观测、未知目录ID；声明总量与目录总量不一致时保留两者，不伪造百分比。
- 成功解码数、流尾残缺及解压预算信息。探索报告只是证据，不等于已写入Lolo数据库或全图恢复。

保留的兼容与安全能力
- GUI 的 StopFlag、ReadyPath、PythonExe、TSharkExe、ServerIps 接口及PID就绪绑定。
- GUI分段落盘与独立CLI连续抓包/回车结束。
- 原生输出UTF8读取、Wi-Fi与隧道裸IP混合接口修正、完整IDB选项与有限section长度校验。
- Steam服务器地址捕获和协议方向试探，沿用 s2c/c2s 导出标签。
- 已知登录请求过滤与登录响应token清理。原ETL/PCAP仍含敏感数据，账号ZIP也不是匿名文件。

用法
1. 完整解压启动器；公服采集页可先点“预检查”。
2. 开始采集时按需要确认Windows管理员权限；真正抓包就绪后才打开配置的官方客户端。
3. 登录并加载想备份的界面，最后使用GUI“结束采集”或独立脚本窗口按回车。
4. 等待导出并另存账号ZIP。不要公开分享原始抓包、账号数据或诊断日志。

不自动下载/安装运行时或游戏。便携版保留已有经校验的Python与TShark依赖；依赖或权限缺失时明确报错。

4_import_player.cmd 是 of-ps 专用入口，不是启动器默认Lolo导入器。Lolo请用启动器“导入数据”，保留UID冲突、备份和完整性确认。

第三方许可证与来源声明继续保留；集成版本不对所有Windows构建、VPN路径、客户端更新或游戏模块作完整兼容保证。
