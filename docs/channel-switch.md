# v1.4.2 进入频道断链修复

登录成功后进入自己的频道时客户端崩溃，最新房间网关日志显示：1001认证、1003登录、1004成功回包都已转发，客户端随后发出1201 `ChangeSceneChannelReq`，网关在`phase=authorize`抛`ValueError`并关闭连接，客户端反复重连。

## 原因

v1.4.1为房间权限加固增加了一条前置检查：1201中的频道ID必须已存在于`rooms.json`。但“自己的频道”可能是尚未登记的动态频道，本应由服务端返回1202/场景观察后自动登记。于是合法进入被误判并断链，属于加固引入的回归。

## 修复

- 1201仍严格验证频道ID是合法uint32；解析不确定、明确关闭、明确满员（且不是自己当前频道）仍拒绝。
- **未登记的频道不再断链**，透明转发给服务端；收到服务端成功响应/场景观察后再自动登记，保持后端为权威。
- 自己当前房间的重入允许；已关闭频道仍不可进入。
- 保留v1.4.1全部能力：1001认证fail-closed、空昵称成功回包补齐、观察异常不丢帧、帧头/长度边界、脱敏握手日志。

## 验证

23项网关专项测试及全量237项回归通过（1项符号链接权限跳过）。测试覆盖未知频道透传与仅服务端响应后登记、关闭/满员/超范围拒绝、当前频道重入、观察异常不丢帧、空昵称回包。本轮没有真实用户重试证据，最终以重新进入频道的结果为准。

## 使用

更新后需重新启动私服，让新网关进程生效；游戏内重新进入频道验证。修复不改存档、数据库或官方资源，也不强停正在运行的游戏。
