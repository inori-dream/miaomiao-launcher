# 发布复核结论（2026-11-24，历史记录）

> 本文是 v1.4.9 之前的历史复核。当前加固分支的新证据见 `hardening-v1.4.9.md`；其中“未启动游戏/服务”的结论仅适用于本文日期，不代表后续验收。

## 结论

**隐私脱敏的源码/启动器组件可作为发布候选；尚未达到“解压即用的完整私服发行包”标准，也不能称为已经完成许可证合规审查。**

经过复核的最新源码/组件包作为发布候选；完整备份工具仍使用已复核的独立附件。不要发布作者原工作目录或旧便携包。

## 账号和 UID

- 源码/附件不应含作者真实展示 UID、内部账号编号、角色名、账号配置、抓包、存档、数据库或管理密钥。检查同时覆盖文本、EXE/DLL、ZIP 全部条目和已知个人标识。
- 默认本地 UID 为合成占位值 `1000000`，并非附送的官服账号或私人存档；SDK 的 `local-session` 是本地固定占位字符串，不是作者登录凭据。
- 新建单机/局域网模式只创建数据库架构，**不再自动复制模板数据库中的个人账号和进度**；已有本地模式存档不被清空，个人进度必须明确导入。
- 无法保证别人不输入某个 UID 数字。当前 UID 网关没有密码/所有权认证；不要将私人存档的服务器向不可信玩家或公网开放。独立空数据库中的同号账号不等于作者官服账号。
- 已知标识和文件类别扫描不是对全部未知秘密的数学保证，仍需人工复查。原始备份输出永远不能当作匿名公共资料。

## 完整性

| 项目 | 现状 |
| --- | --- |
| 启动器 EXE、SDK DLL、图标、核心脚本 | 组件包包含 |
| 备份工具源码、使用说明、协议许可证 | 源码包和组件包包含 |
| 完整备份工具 Python/TShark/解析依赖 | 单独 Windows 备份工具附件包含 |
| 启动器 Python | 未捆绑；安装 Python 3.12 x64 |
| Lolo.exe、config、data、Resource、空模板数据库 | 未捆绑；自行从合法来源提供 |
| 游戏客户端 | 未捆绑；单机需要兼容本地客户端 |
| 密码或官服账号所有权认证 | 未实现；仅本地 UID 模式 |
| 跨电脑首次启动/实际游戏协议验证 | 本次未完成 |
| 游戏图标授权、整体开源许可证及GPL发行义务 | 维护者仍需确认 |

`python preflight.py` 提供只读文件/架构检查。返回缺服务资源是组件包的预期现状，不应隐藏缺项或自动从作者安装目录补入私人资源。

## 账号数据说明是否具备

具备：[完整流程](login-and-data.md) 与 [备份工具操作说明](../backup-tool/README.md)。覆盖正常官服登录、抓包启动顺序、逐项界面/分页加载、摘要核对、UID与内部ID区分、ZIP目录结构、确认导入、备份与模式隔离、家园归档限制，以及抓包令牌风险。同时覆盖日常实际使用的本地 UID 登录操作步骤、渠道弹窗处理与已知现象。

仅凭 UID 不能抓取官服远程存档。获取数据依赖合法本人登录、服务端仍正常响应和协议版本兼容；不能承诺百分之百迁移。

## 本次测试范围

- 启动器与 SDK 构建；SDK 本地回调测试。
- 启动器回归测试，包括新建两种模式不继承模板账号、已有账号不被覆盖、源数据库不变。
- 备份工具合成协议分帧/Snappy、已知登录请求剔除、登录响应令牌清理、双向流和家园导出测试。
- Windows PowerShell 5.1 中文脚本语法检查、依赖检查 CLI、源码白名单、附件完整性与已知个人标识扫描。
- 界面：单机/联机各检查 1240×900 与 1040×740 两种尺寸，按钮文字、兄弟控件重叠与边界检查均通过；小窗使用内容滚动，不强行挤压按钮。未对所有系统 DPI 比例作验证。
- 没有实际登录官服、实时抓包、启动游戏/服务、测试公网身份安全或上传 GitHub。
