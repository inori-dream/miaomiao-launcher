# v1.4.1 空昵称登录回包兼容

国服当前客户端热补丁的登录成功处理有一个额外条件：`PlayerLoginRsp.player_name` 不能为空。即使服务端返回成功状态1，空昵称也会显示“暂时无法登录”并不再请求主数据。

本轮日志确认服务端登录Name为空；静态解析当前IFix补丁确认OnLoginSuccess先检查PlayerName是否为空。隔离空库的真实后端1004回包也为空名，修复后同一回包昵称非空、status不变，并保持1006正常。

## 修复范围

房间网关只对明确成功status1、字段11缺失或全部为空的1004补本地显示名：先使用账号已有昵称，否则使用UID显示名。不会覆盖已有昵称，不修改成功/失败状态，不写数据库，不重建或删除存档。

保持原packet_id、seq_id、分包信息、flag、未知头字段；只更新必要body_len。压缩回包用合法Snappy raw编码。解析不确定、未知flag、多包或失败响应保持原字节，不能为兼容猜状态。

服务端透传与房间观察分离：完整原帧先转发，观察解析异常只记脱敏诊断，不丢包或触发自动移动。客户端登录认证与房间权限仍严格验证。

握手日志只记录随机连接编号、方向、消息号、长度、flags/序列/分包计数、转发计数和异常类；不写昵称、UID、登录token或消息正文。

## 验证与边界

18项新增透传/空名测试，以及全部已有回归通过。隔离真实后端验证成功1004空昵称可补齐、status保持1，1006仍正常。客户端当前补丁的实际门槛已确认，但旧补丁文件缺失，不能断言该门槛一定是昨晚才新增。

本轮不会改官方资源、回滚公服补丁或强制关闭用户游戏。应用更新需游戏和服务空闲；更新后重新启动私服客户端使新网关生效。最终用户登录恢复仍应以重试结果为准。
